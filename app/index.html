Do exemplo ao seu experimento
O navegador ajuda a formular a decisão. Para avaliar textos novos com Jev, rode o servidor no seu computador. A chave fica no ambiente do servidor, nunca no navegador.
git clone https://github.com/inematds/jev.git
cd jev
python3 -m jev_lab serve
Abra http://127.0.0.1:8765. Sem chave, use os exemplos e a avaliação de regras disponível na CLI.
