# Regras do projeto jev

Ler este arquivo, `context/overview.md`, `context/current-state.md` e `tasks/current.md` nessa ordem.

Conta de destino: inematds. Autor e committer: inematds <inematds@gmail.com>. Publicação via Git. Não consultar nem manipular Vercel.

Este é o repositório de aplicação. A versão v1.5.1 implementa o laboratório educacional. Não declarar integração operacional ou benchmark Jev real sem evidência. Preservar distinção entre dados medidos, relatos e simulação. Conferir fontes oficiais antes de alterar contratos ou preços. Não versionar segredos ou dados pessoais.

Versionamento conforme regras globais: patch incrementa último campo; minor incrementa campo intermediário sem zerar patch; major zera os inferiores. Registrar alterações no CHANGELOG.

Não citar a fonte pessoal indicada pelo usuário nem publicar os documentos recebidos por ele. No repo jev, `fontes/originais/` e `fontes/manifest.json` ficam somente locais e ignorados pelo Git. Não usar `git add -f` nesses caminhos.
